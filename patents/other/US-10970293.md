# US-10970293-B2 — Ranking search result documents

- **Изобретатели:** Mike Bendersky, Marc Alexander Najork, Donald Metzler, Xuanhui Wang
- **Тема:** персональный поиск / документы с ограниченным доступом / перенос поведения

## Суть в двух словах

Патент описывает, как **оценить закрытый документ по поведению чужих пользователей с чужими закрытыми документами, похожими по признакам**.

Ситуация, которую он решает. Документ виден только владельцу, поэтому статистики взаимодействий по нему нет и быть не может. Обучать на данных самого владельца нечем: у одного человека слишком мало событий.

Решение: считать **запросонезависимую оценку** документа не по нему самому, а **по его признакам**. Для каждого признака берётся статистика **прошлых взаимодействий других пользователей с их собственными закрытыми документами**, обладающими тем же признаком. Причём — существенная деталь — берутся взаимодействия по **другим запросам, не содержащим признаков текущего запроса**, чтобы оценка осталась запросонезависимой.

## Формула, по пунктам

Всего 7 пунктов, независимый один — пункт 1.

**Пункт 1 (независимый) — четыре шага:**

1. Получить **запрос**, введённый пользователем.
2. Определить **отвечающие документы**, являющиеся **документами с ограниченным доступом** этого пользователя — доступными **только ему и назначенной им ограниченной группе**.
3. Выделить **признаки запроса**.
4. Для каждого отвечающего документа: выделить **признаки документа** и построить **запросонезависимую оценку** на основе оценок его признаков. Каждая такая оценка опирается на **прошлые взаимодействия соответствующих пользователей с другими документами** — отличными от рассматриваемого, но **обладающими теми же признаками**, — когда те показывались в ответ на **другие запросы, не содержащие ни одного признака текущего запроса**. Эти другие документы — **закрытые документы других пользователей, недоступные** данному.

**Зависимые пункты:**

| № | Что добавляет |
|---|---|
| 2–7 | Уточнения состава признаков и агрегирования оценок |

## Что это значит для SEO

Для веб-продвижения патент неприменим, но содержит две методологически ценные идеи:

**1. Поведенческий сигнал переносится через признаки, а не через документ.** Документ, по которому нет ни одного взаимодействия, получает оценку по статистике похожих. Это прямой ответ на вопрос, как система оценивает то, о чём не имеет данных, — и та же логика видна в [[US-9305099]], где вес новой ссылки выводится по сходству её признаков с известными.

**2. Запросонезависимость обеспечивается явным исключением.** В формуле прямо сказано: берутся только взаимодействия по запросам, **не содержащим признаков текущего**. Разделение статических и запросозависимых сигналов здесь не декларация, а конструкция.

**3. Приватность соблюдена на уровне формулы.** Используется статистика по чужим документам, но сами документы остаются недоступными. Это показывает, как агрегированные поведенческие данные применяются без раскрытия содержимого.

**Оговорка.** Это патент, а не подтверждение работающего механизма. Google патентует существенно больше, чем внедряет, и патент 2016 года мог не дойти до продакшена или дойти в неузнаваемом виде. Использовать как рамку для понимания логики, а не как описание текущего алгоритма.
