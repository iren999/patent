# US-2013282699-A1 — Using Authority Website to Measure Accuracy of Business Information

- **Владелец:** Google (заявитель Google Inc., сейчас Google LLC)
- **Подана / Опубликована:** 14.01.2011 / 24.10.2013
- **Приоритет:** 14.01.2011
- **Изобретатели:** Gang Feng, Bo Zheng, Fang Chu, Dylan Myers
- **Тема:** локальный поиск / достоверность агрегаторов / официальный сайт как эталон
- **Ссылка:** https://patents.google.com/patent/US20130282699A1/en

> ⚠️ **Не ссылочное ранжирование.** «Authority website» здесь — **официальный сайт самой организации**, служащий эталоном правды, а не авторитетный донор ссылок. Карточка вынесена в `patents/other/`. Это **заявка (A1)**, а не выданный патент.

## Суть в двух словах

Патент описывает, как **оценивать достоверность агрегаторов, сверяя их данные с официальным сайтом организации**.

Ситуация, которую он решает. Сведения об организации разбросаны по десяткам справочников, и они противоречат друг другу: разные телефоны, устаревшие адреса, неверные часы работы. Нужно решить, кому верить.

Решение: взять **авторитетную страницу с сайта самой организации**, сравнить с ней данные, полученные из каждого агрегатора, и выставить **оценку точности для пары «организация + агрегатор»**. Из данных с высокой оценкой собирается **достоверный набор сведений**.

## Формула, по пунктам

Всего 18 пунктов. Независимых три — 1, 7 и 13. Разбираем пункт 1.

**Пункт 1 (независимый) — пять шагов:**

1. Получить **сведения об организациях** из **агрегирующих источников**.
2. Получить **авторитетную страницу** с **авторитетного сайта** одной из этих организаций.
3. **Сравнить** сведения об организации из агрегаторов с информацией, **извлечённой из авторитетной страницы**, и получить результат сравнения.
4. Сформировать **оценку точности** для **сочетания «данная организация + данный агрегирующий источник»** на основе результата сравнения.
5. Сформировать **набор достоверных сведений** об организации на основе этих оценок.

**Зависимые пункты:**

| № | Что добавляет |
|---|---|
| 2 | Оценки точности разных агрегаторов **сравниваются между собой** |
| 3–6 | Уточнения извлечения данных и формирования итогового набора |
| 7–12, 13–18 | Те же механизмы как система и как носитель |

## Что это значит для SEO

**1. Официальный сайт — источник истины, а не один из голосов** (шаг 2). Собственный сайт организации имеет приоритет над любым количеством справочников. Расхождение между сайтом и агрегаторами разрешается в пользу сайта.

**2. Достоверность агрегатора оценивается отдельно по каждой организации** (шаг 4). Оценка ставится паре «организация + источник». Справочник, точный в одной отрасли, не получает доверия автоматически в другой.

**3. Практический вывод для локального SEO прямой.** Поддерживать актуальность на собственном сайте важнее, чем рассылать правки по справочникам: сайт служит эталоном, по которому справочники и проверяются.

**4. Извлекаемость данных со страницы имеет значение** (шаг 3). Информация сравнивается с тем, что **извлечено** из авторитетной страницы. Контакты и часы работы, доступные только на картинке или в скрипте, эталоном не станут.

**Оговорка.** Это заявка на патент, а не подтверждение работающего механизма, и не выданный патент. Google патентует существенно больше, чем внедряет. Использовать как рамку для понимания логики, а не как описание текущего алгоритма.
